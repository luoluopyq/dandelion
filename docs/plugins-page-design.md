# 插件模块页面设计

范围：只调整 PluginManagerPanel 与 AgentPluginsPanel 的模板、样式和可访问性标签；保留全部原有脚本、调用、状态判定、安装确认和配置结构。

## 设计语言

纸面 #FAF8FF，内容面 #FFFFFF，正文 #29213D，强调紫 #7557C8，边界 #E2DEEB，次级文字 #77717E。实际使用产品主题变量，兼容暗色。
字体使用现有 Geist / PingFang SC。页面标题 26px，条目名称 15px，说明 13px，辅助信息 12px。内容左对齐，段落控制行长。

```text
插件                              刷新  添加
为当前对话选择 Agent，管理可用技能与工具。
Agent 2    技能 2    工具 1    发现
──────────────────────────────────────────
当前对话使用：蒲公英原生    切换提示
可用 Agent
[蒲] 蒲公英原生       内置无需安装    返回对话
[C ] Claude Code      蒲公英已安装    使用  设置
[O ] OpenCode         可按需安装      安装  设置
```

技能和工具：统一整行列表，左侧图标与可换行摘要，中间明确展示状态，右侧操作。发现页使用简明目录搜索区，结果列表展示描述和安装形式。配置和链接安装表单保留在页内，字段有可读标签。

## 方案复核

不增加市场推荐、分类、统计或新的业务操作。取消原本大卡片、浮动的两栏短条目、装饰性“扩展”眉题和大面积紫色搜索底板。用一个共享的列表结构表达扩展能力，只有当前选中的 Agent 使用轻量紫色边缘提示。

宽屏约 1120px 内容上限；窄屏操作换行、表单转单列，避免名称和按钮挤压。保留安装进度与取消按钮，补齐键盘焦点和减少动态效果适配。

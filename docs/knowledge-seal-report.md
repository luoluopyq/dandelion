# 本地知识模块封板验收

日期：2026-10-18。范围：独立知识收集、原件保存、阅读编辑、主题归属、检索与对话保存、项目 Wiki 兼容，以及本机 macOS 验证构建。

## 已完成

- 默认全部知识；文章、笔记、代码、文件及链接无需建立项目。标题可省略。项目文档保持目录扫描、增量构建和出处定位，入口独立。
- 保存文件副本后再解析。空 README、未支持附件、编码及解析失败均保留原件，可补笔记、重试或导出。视频和图片仅按实际提取范围参与检索。
- 同路径同快照重复添加不增长；原件更新建立版本，保留笔记。没有可提取文本的二进制附件也按原件变化区分版本。共享快照只在最后一个版本引用删除后清理，用户原文件不删除。
- 旧资料可在原身份下编辑，避免迁移到新页面后复制出第二份。归档默认个人空间后，新保存内容进入新的有效个人范围。
- 自动归类由用户明确允许模型使用后开启；优先使用既有主题，新主题显示建议，手动归属固定。版本校验阻止晚到结果覆盖，进程内同条目并发请求只调用一次模型。分类任务使用内部数据目录，不依赖项目目录存在。
- 个人知识沿用既有本地检索及权限/外发策略。对话中的一般知识保存不因当前工作项目而被强制写成项目 Wiki；整篇答复完整保存，不按通知长度拆成多个条目。
- 项目零来源在调用模型前停止。项目目录迁移与编译串行，写入前解析知识目录，消除已写入台账在并发迁移中暂时读不到的路径。
- 本机 Tauri Rust/API 版本对齐，锁定 API 2.12.4、CLI 2.12.3；应用兼容补丁修复 npm 审计告警，未使用强制跨大版本升级。

## 页面可用性检查

使用真实 Vue 组件和隔离示例 IPC 进行交互检查，未修改用户实际知识：

- 添加入口不要求项目和目录；输入正文即可启用保存。
- 保存后列表和阅读区更新；代码按代码块阅读。
- 搜索与类型、主题、收藏筛选组合工作。
- 空 README 保持在列表，正文区显示原因、补笔记、重新提取和导出入口。
- 编辑未保存时，切换导航需要明确确认，不静默丢弃修改。
- 源码/内容区、元信息与处理状态分开；底部模型策略明确说明是否向配置模型发送摘录。
- 修复 Wiki 失败详情中不合法的 HTML 嵌套，前端构建没有该结构告警。

## 当前能力边界

图片 OCR、视频转写与时间码检索、网页全文抓取、目录持续监控及新的语义嵌入模型未实现。文件、链接原地址及笔记可以先收集；界面不会把“文件已保存”显示成“媒体已理解”。个人资料外发策略仍需明确允许，关闭模型使用不影响本地保存与全文查找。

本轮交付是本机 macOS 验证包与源码，未发布升级，未覆盖系统 Applications 中的旧安装。测试涵盖真实核心存储和桥接，以及组件交互；未用用户真实资料和付费模型做破坏性测试。

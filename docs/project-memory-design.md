# 项目记忆：页面与功能设计

目标：让用户首先看清已经确认的项目约定、仍需确认的提议，以及修改与忘记的来龙去脉。
保存不等于每轮必用；对话仍由核心按项目范围、确认状态和问题相关性选择记忆。

## 页面结构

```text
项目记忆                         检查效果   ＋ 添加记忆   更多
项目 [aiproject ▾]   当前工作目录 /…/aiproject

已确认 8       待确认 2       变更记录
搜索记忆…                       类型 [全部 ▾]    刷新
┌────────────────────────────┬──────────────────────────┐
│ 项目约定列表                │ 选中的记忆                │
│ 内容摘要、类型、更新时间     │ 完整正文、来源、范围、状态 │
│                            │ 编辑 / 确认 / 忘记         │
└────────────────────────────┴──────────────────────────┘
```

窄屏改为上下排列。空态直接引导添加，不展开空表单和检查工具。

## 视觉与取舍

沿用蒲公英主题，参考浅色值：纸面 #FAF8FF、正文 #29213D、强调紫 #7557C8、分隔线 #E2DEEB、次级文字 #77717E、待确认 #946B26。
实际组件使用主题变量，同时适配暗色。字体沿用 Geist 与 PingFang SC；26px 页面标题、15px 正文、12px 元信息。
列表与详情统一左对齐，正文控制行长，避免把每块内容包装成大卡片。

方案核对后取消了统计仪表盘、常驻新增大表单和常驻模型诊断。状态只用于区分已确认、待确认与历史；视觉重点留给记忆正文。

## 功能行为

- 已确认：搜索、按类型筛选、查看完整内容与来源、编辑、忘记。
- 待确认：明确标示不会进入任务；支持直接确认、编辑后确认、忽略。
- 变更记录：从现有不可变事件账本展示添加、编辑、确认和忘记，不把历史版本重新算作当前记忆。
- 添加与编辑：按需打开弹窗；事实与偏好保留现有能力；修订保持原类型；字节长度统一校验。
- 来源：沿修订链回溯原始来源，能确定来源对话时提供跳转。
- 检查效果：单独弹窗输入问题，展示核心选择的内容；预算沿用实际配置；算法得分与 token 信息收在诊断中。
- 更多：保留旧版记忆文件入口与按需运行的项目关系、应用运行统计。
- 项目切换：清空旧项目的编辑、预览和反馈；晚到的响应不能覆盖新项目；写操作始终使用发起时的项目范围。

不新增 Agent 循环，不变更记忆确认、项目隔离和撤回的核心规则。
